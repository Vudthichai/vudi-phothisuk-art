## Additional public paths and legacy handling

`/contact` and `/contact/` redirect to About; they are not two additional public content pages. The generated redirect list also preserves recorded earlier artwork URLs; see [redirect evidence](evidence/generated-redirects.txt). Unknown routes return 404/noindex. `/dev/…` previews are excluded from the public route catalog/build. Asset directories such as `/forest-preview/images/` and `/studio-editions/…` are public resources, not separate editorial pages. `robots.txt`, `sitemap.xml`, `build-info.json` and public media are inventoried separately.

Direct source manifests and unused assets must not be confused with indexed pages. A robots disallow for a JSON manifest is not file protection. A successful HTTP 200 is not proof of Google indexing; GSC verification remains outstanding.
