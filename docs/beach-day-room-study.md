# Beach Day and supplementary-view refinement

Beach Day uses the last artist-supplied IMG_7497.jpeg crop (2395 × 3630) for its
hero and collection image. Optimized copies preserve its composition and colors.
The earlier weak detail image is omitted from display; original assets remain.

The boho study uses a generated empty-room background and a separate HTML image
layer containing the exact same Beach Day photograph as the hero. The painting
is never regenerated. Placement and scale are illustrative, not verified room
measurements. No supplied videos are published.

Arctic Waves' detail view now uses contain sizing to show the entire selected
close-up rather than an enlarged center crop. Its naturally narrow source limits
how wide the image can appear without cropping or distortion.

Golden Sand Beach's room section now pairs a larger image with a concise
paragraph grounded in the visible painting and existing room study. The main
artwork description and metadata remain unchanged. No extra panel frames added.
